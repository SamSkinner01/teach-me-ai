## The training loop

You now have every piece. Training a neural network is this loop:

```text
initialize the weights (He initialization) and the biases (zeros)
repeat for each epoch:
    forward:   z1 = dense(X, W1, b1);  h = relu(z1);  logits = dense(h, W2, b2)
    loss:      L = mean cross-entropy(logits, labels)
    backward:  start from dL/dlogits, push it back through dense, relu, dense
    update:    every parameter -= learning_rate * its gradient
```

Each line is a function in your library. The milestone exercise below assembles them into a network that learns.

## How do you know it works?

On these toy datasets you can see the answer. On real data you can't, so you watch the numbers: the training loss should fall steadily, and the accuracy should rise.

There's one more thing to watch, which matters on real datasets. A network with enough weights can memorize its training examples instead of learning the pattern, a problem called **overfitting**. The fix is to keep some data aside, a **test set**, that the network never trains on, and measure accuracy there. You'll do exactly that with MNIST in the capstone.
